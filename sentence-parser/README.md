# 长难句 × 墨墨

把**背单词**和**练长难句**合成一件事：从墨墨背单词读取你今天背的词（优先挑忘记、模糊、顽固的），让 AI 用这些词写一个考研级别的长难句，你按「断句 → 抓主干 → 标成分 → 翻译」一步步拆解，系统逐项判分讲解，最后把这个句子写回墨墨，成为这些单词的例句。

```
墨墨今日单词 ──► AI 用这些词写长难句 ──► 五步拆解练习 ──► 判分 + 讲解
     ▲                                                   │
     └──── 写入例句 / 没记牢的词提前复习 / 生词加入学习计划 ◄──┘
```

没有墨墨账号或 AI Key 也能用：内置 15 个长难句（其中 13 个出自 2007–2018 年考研英语真题），每句都有人工标注的完整解析。

## 快速开始

需要 [Node.js](https://nodejs.org/) 20.19+ 或 22.12+。

```bash
cd sentence-parser
npm install
npm run dev
```

浏览器打开 <http://localhost:5173/>，到「设置」里填两样东西：

1. **墨墨开放 API Token**：打开墨墨背单词 App →「我的」→「更多设置」→「实验功能」→「开放 API」，复制 Token。填好后点「保存并测试连接」，能看到今日学习进度就说明连上了。
2. **AI 模型**（二选一）
   - **Claude**（默认，`claude-opus-5-5`）：填 Anthropic API Key。想更快更省可以换 `claude-sonnet-5-5`，或把思考强度调成「快」。
   - **OpenAI 兼容接口**：DeepSeek、通义千问等，填接口地址、模型名和 Key，设置页有一键预填。

也可以把这些写进 `.env`（参考 `.env.example`），网页里保存的值会覆盖 `.env`。

> 在国内访问 Anthropic API 需要代理：设置 `HTTPS_PROXY` 后用 `NODE_USE_ENV_PROXY=1 npm run dev` 启动（Node 22.21 及以上）。

## 练习流程

每个句子分五步。结构和翻译分开练，是为了避免一边划结构一边想中文造成的认知超载（原理见 [DESIGN.md](../DESIGN.md)）。

| 步骤 | 你要做的 | 系统怎么判 |
|---|---|---|
| 1 断句 | 点击单词之间的空隙，把句子切成意群 | 对照参考切分：切对、漏切、多切分别标出；多切只扣半分 |
| 2 抓主干 | 先标谓语，再标主语、宾语 / 表语 | 只要选中参考答案里的核心词、且没把修饰成分选进来就算对 |
| 3 标成分 | 给每个意群选：主干、定语从句、同位语从句、非谓语作状语…… | 完全正确得 1 分，同一大类（如定语从句选成非谓语作定语）得 0.5 分 |
| 4 翻译 | 先自评目标词想没想起来，再写译文 | AI 按结构理解、词义、漏译、表达批改；给出修改建议和直译 / 意译 |
| 5 解析 | 看彩色结构图、分层结构、难点、目标词 | 一键同步到墨墨（见下） |

成绩会存进「记录」页，按成分类型统计正确率。你最近错得多的结构（比如同位语从句），AI 出题时会特意放进句子里。

## 和墨墨的联动

读取：

- **今日单词**：带上墨墨里的首次反馈（忘记 / 模糊 / 认识）和「顽固词」标记
- **顽固 / 遗忘词**：学习记录里标为顽固或上次忘记的词
- **云词本**：任选一个云词本里的词

「智能选词」优先挑还没练过的词，其中忘记 > 顽固、模糊 > 新学。点「下一句」会自动换下一批词。

写入（都需要你在解析页手动点按钮）：

- **存为墨墨例句**：把这个长难句和译文写成目标词的例句，下次在墨墨复习这个词就能看到
- **提前复习**：翻译时自评「模糊 / 没想起来」的词，让墨墨提前安排复习
- **加入学习计划**：句子里不在你墨墨计划中的生词，勾选后一键加入

用到的接口全部来自[墨墨开放 API](https://open.maimemo.com)（路径和请求格式对照官方 [memo-api-cli](https://github.com/maimemo/memo-api-cli) 实现）。开放 API 不支持直接提交「认识 / 不认识」，所以用「提前复习」把练习结果反馈给墨墨的记忆算法。

## AI 出的题靠谱吗

AI 返回的分析必须通过逐词对齐校验才会展示：意群拼起来必须和原句一字不差、主干的每个词都要在句中找到、每个目标词都要真的出现在句子里、句长要符合所选难度。不合格会把具体问题反馈给 AI 自动重写一次，还不合格就报错让你重试。语法分析本身仍可能有争议，遇到觉得不对的地方，可以对照内置真题的人工解析。

每生成一句会消耗几千到一万多 token（含模型思考），批改翻译用的是低思考强度，花费更少。

## 数据与隐私

- 所有数据都在本机 `data/` 目录：`settings.json`（Token 和 Key，权限 600）和 `db.json`（句子、练习记录）。这个目录不会提交到 git。
- 服务默认只监听 `127.0.0.1`，并拒绝非本机 Host 的请求和非 JSON 的写请求，其他网页无法借你的浏览器调用它。

## 项目结构

```
server/            本地后端（Express）
  maimemo.ts         墨墨开放 API 客户端（按平台 20 次 / 10 秒的上限自动排队）
  llm/               Claude 与 OpenAI 兼容接口、提示词、生成 / 分析 / 批改
  app.ts             API 路由；index.ts 启动入口
  builtinSentences.ts 内置真题句库（人工标注）
shared/            前后端共用：成分标签、分词对齐、评分、选词
src/               前端（React + Tailwind）
test/              Vitest 测试
```
